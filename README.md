# 🐾 ONG PATRE

Aplicativo mobile desenvolvido para apoiar uma instituição sem fins lucrativos dedicada ao resgate, proteção e adoção responsável de animais em situação de abandono.

O projeto foi criado com o propósito de aproximar animais resgatados de possíveis adotantes por meio de uma plataforma intuitiva, moderna e acessível. Além de incentivar a adoção consciente, o aplicativo também oferece recursos para apoiar financeiramente a instituição através de doações, contribuindo diretamente para o cuidado, alimentação e bem-estar dos animais.

## ✨ Objetivo

Desenvolver uma solução tecnológica capaz de fortalecer o trabalho da ONG, facilitando o processo de adoção e aumentando a visibilidade da causa animal.

## 🚀 Principais funcionalidades

- 🐶 Catálogo de animais disponíveis para adoção
- 📋 Informações detalhadas de cada animal
- ❤️ Processo de adoção responsável
- 💰 Área para realização de doações
- 📱 Interface intuitiva e responsiva
- 🏡 Divulgação da missão e das ações da instituição

## 🛠️ Tecnologias utilizadas

- React Native
- Expo
- TypeScript
- JavaScript
- CSS
- Git e GitHub

## 🎯 Impacto do projeto

Mais do que um aplicativo, este projeto busca utilizar a tecnologia como ferramenta de transformação social, promovendo a adoção responsável, incentivando doações e ampliando o alcance das ações desenvolvidas pela instituição.
